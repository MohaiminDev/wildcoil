# Stage 1 Runtime Assets

This directory holds project-bound visual assets for the `Sunset Overpass` production pass.

Do not reference assets from `$CODEX_HOME/generated_images` directly. If an image is used by the game, copy it into this tree and record provenance in `docs/asset_provenance_register.md`.
