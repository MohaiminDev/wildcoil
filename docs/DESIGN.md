# Design

## Active Direction
- `Rift Road: Beasts of the Afterglow` is the active game direction.
- `docs/game-story.md` is the story bible.
- `docs/game_spec.md` is the living design/product spec.
- `to-do.md` is the active milestone tracker.

## Design Constraints Visible In Repo
- Build an original macOS-first 2D arcade beat-'em-up prototype.
- Keep original content separated from influence/reference material.
- Track asset provenance in `docs/asset_provenance_register.md`.
- Focus current implementation on the team-review Stage 1 prototype path.

## Design Change Rules
- Read `docs/game-story.md` before changing names, factions, stages, heroes, bosses, or tone.
- Update `docs/product-specs/index.md` when product behavior changes.
- Update `to-do.md` when task scope or validation changes.
- Add validation for behavior changes in `tests` where practical.
