# Wildcoil v0.1.0 Tester

## Highlights

- Three playable stages: Relay Clearing, Coil Depths, and Storm Crown
- Two playable hunters: Mira Coil and Zeph Rush
- Persistent mission-board progression with rank and time tracking
- Keyboard-first macOS build with controller mappings still present in the input layer
- High-contrast HUD, reduced-motion, lower screen-flash, and focus-loss auto-pause options

## Included Artifacts

- `Wildcoil-phase3-finale-macos.zip`
- `Wildcoil-phase3-finale-macos.zip.sha256`

## Install Notes

- The macOS build is currently unsigned and unnotarized.
- If Finder warns about the app, use Finder's `Open` flow or launch the binary directly from `Wildcoil.app/Contents/MacOS/Wildcoil`.
- For isolated local testing, launch with `WILDCOIL_SAVE_PATH=/absolute/path/to/profile.json`.

## Known Issues

- No physical controller was attached on this machine during the final release pass, so controller behavior is still covered by the synthetic runtime suite plus earlier input validation rather than a live hardware smoke.
- The release is intended for internal tester feedback, not broad public distribution.
